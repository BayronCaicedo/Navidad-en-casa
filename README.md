# Navidad en Casa 🎄

Tienda virtual de decoraciones navideñas artesanales para el hogar, desarrollada como proyecto universitario aplicando las etapas del ciclo de vida del software.

## Descripción

**Navidad en Casa** busca ofrecer una experiencia sencilla, cálida e intuitiva para conocer y comprar decoraciones navideñas elaboradas a mano. El catálogo estará enfocado en productos para diferentes espacios del hogar, como sala, comedor, cocina, baño, puertas y zona del árbol de Navidad.

Entre los productos se contemplan muñecos navideños, manteles, caminos de mesa, cojines y fundas decorativas, adornos para sillas, decoración para puertas, cubrepiés para el árbol y otros artículos artesanales.

## Objetivo

Diseñar y desarrollar una página web intuitiva, llamativa y responsive que permita promocionar y comercializar productos navideños artesanales para el hogar.

## Funcionalidades previstas

- Página de inicio con identidad visual navideña.
- Catálogo de productos artesanales.
- Categorías por espacios del hogar.
- Buscador y filtros básicos.
- Vista detallada de productos.
- Carrito de compras.
- Modificación de cantidades y cálculo del total.
- Persistencia temporal del carrito con `localStorage`.
- Formulario de datos del cliente.
- Resumen del pedido.
- Envío del pedido mediante WhatsApp.
- Secciones de promociones, nosotros y contacto.
- Diseño adaptable a computador, tableta y dispositivos móviles.

## Estrategia de ramas

El proyecto utilizará una estructura sencilla para facilitar el trabajo colaborativo:

- `main`: versión estable del proyecto. Aquí se integrarán únicamente cambios revisados y listos para entrega o publicación.
- `dev`: rama principal de desarrollo e integración del equipo.
- `feature/nombre-funcionalidad`: ramas temporales para desarrollar funcionalidades específicas cuando sea necesario.

El flujo recomendado será:

```text
feature/... → dev → main
```

Los cambios desarrollados se integrarán primero en `dev`. Una vez revisados y probados, podrán incorporarse a `main`.
